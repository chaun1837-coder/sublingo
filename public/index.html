Sau khi tải file SRT lên, nội dung gốc và bản dịch sẽ được đặt cạnh nhau để bạn dễ rà soát từng câu.

ⓘ
Cơ chế bảo vệ file: Trình đọc chỉ cho phép chỉnh sửa vùng lời thoại. Số thứ tự, dòng thời gian, phần metadata và dấu phân cách được giữ lại từ file gốc khi xuất. Bản triển khai gửi từng nhóm lời thoại tới backend để gọi AI; backend không lưu API key hay file phụ đề. Số thứ tự, timestamp và phần metadata luôn được giữ ở trình duyệt.
